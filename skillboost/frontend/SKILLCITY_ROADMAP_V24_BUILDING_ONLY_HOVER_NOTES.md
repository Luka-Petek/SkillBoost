# SkillCity roadmap v24 — building-only hover

## Fokus
Ta verzija se vrne na boljšo v21 osnovo in odstrani vse hover/info dodatke, ki so se odpirali čez mapo.

## Kaj je popravljeno
- hover na zgradbi zdaj spremeni samo zgradbo
- odstranjen je hover preview info box iz mape
- odstranjena je hover preview pot / dodatne črte
- odstranjen je active map callout, ker so podrobnosti že v desnem mission panelu
- odstranjen je focus info overlay v mapi
- lokalni label na zgradbi se pokaže samo za active/current node, ne za vsak hover
- hover na zgradbi ima samo:
  - rahel lift
  - bolj oster tower
  - boljši badge
  - čist glow na sami zgradbi
- klik še vedno normalno izbere misijo
- desni mission panel ostane glavni vir informacij
- build preverjen z `npm run build`
