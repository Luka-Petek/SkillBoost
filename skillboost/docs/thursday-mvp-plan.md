# SkillBoost MVP plan do četrtka

## Must-have

- Docker Compose z MongoDB, backendom in frontendom.
- Backend seed podatki iz JSON datoteke.
- Pregled veščin.
- Izbira izziva.
- Oddaja odgovora uporabnika.
- Mock AI feedback.
- Shranjevanje rezultata.
- Poročilo napredka z osnovnimi metrikami.
- Knjižnica promptov za kasnejši LLM.

## Nice-to-have

- Prava avtentikacija.
- Mentor role.
- Admin urejanje veščin.
- Prava LLM integracija.
- Export poročila v PDF.

## Demo flow

1. Zaženi `docker compose up --build`.
2. Odpri `http://localhost:3000`.
3. Izberi demo uporabnika.
4. Izberi veščino in izziv.
5. Oddaj odgovor.
6. Pokaži mock AI feedback.
7. Pokaži poročilo napredka in točke.
8. Pokaži knjižnico promptov kot pripravo za LLM integracijo.
