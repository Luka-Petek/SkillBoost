# SkillCity roadmap v26 — better fit inside the map

## Fokus
- razširjena / bolj uravnotežena mapa
- vizualno manjše zgradbe in landmark modeli
- še vedno dovolj velike hit-area za miško
- nič dodatnega clutterja na mapi

## Glavne spremembe
- mapa ima več vizualnega prostora v layoutu
- desni stolpec je nekoliko bolj kompakten, zato mapa bolje pride do izraza
- zgradbe so manjše, da bolje sedijo v mapi
- landmark modeli so malo manjši, da ne blokirajo sosednjih node-ov
- district labeli so bolj kompaktni
- character ostane v ospredju, a je bolj kompakten
- za node je dodana večja nevidna hit-area, da je z miško lažje zadeti vse elemente
- build preverjen z `npm run build`
