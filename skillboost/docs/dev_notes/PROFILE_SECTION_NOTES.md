# Moj profil section

Added a cleaner, full profile section with:

- profile hero card with initials/avatar
- role/email/streak metadata
- compact progress stats
- editable goals and target skills
- tag-style display for goals and skill preferences
- coach insight cards for best skill, next focus and active training
- responsive styling in `src/styles/10-profile-section.css`

Frontend build was verified with `npm run build`.
